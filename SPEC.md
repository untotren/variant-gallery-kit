Build a dependency-free ES module `variantGallery` plus stylesheet. Input: `media: [{id, src, alt, kind: 'image'|'video', order}]`, optional `variantMedia: Record<variantId, mediaId[]>`, `defaultHeroId`, and an explicit `selectedVariant` setter. Behaviour as a deterministic state machine: initial hero = defaultHeroId (never derived from the first variant); hero changes only after an explicit `select(variantId)` call; thumbnails are keyboard-navigable (roving tabindex, arrow keys, Home/End), the hero has an accessible name, reduced-motion disables transitions, layout is responsive (thumbnail strip below on narrow viewports, side on wide) via container queries or a single breakpoint, media order is respected. No network calls, no product/store concepts beyond ids. Tests (Node test runner + jsdom): default state, explicit selection, selection of a variant with no media leaves hero unchanged, keyboard navigation, order, reduced-motion flag. Fixtures: generated solid-colour SVGs committed in the repo with fictional labels. Demo page included.
